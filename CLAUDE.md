# Workshop editing guidance

This is the standalone first workshop. The canonical three-session series is CUNY-AI-Lab/sandbox-series. HTML is the presentation authority.

Use the frontend-design skill for visual changes. Keep desktop headings at 32px maximum and preserve the neutral dark palette. Screenshot slides reserve nearly the full viewport for images, with supporting instructions in Notes.

Workshop 1 requires only individual access and Sandbox sign-in. Preserve exact demonstration prompts and original disciplinary examples. Record justified copy changes in review manifests. Run `python3 scripts/check_workshop.py --write` after edits, then run without `--write` to verify.

Keep keyboard navigation, visible focus, image alternatives, and reduced motion accessible. Do not add Co-Authored-By commit lines. Use the consolidated repository for future changes across all three workshops.
